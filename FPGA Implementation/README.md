# FPGA Implementation

- CHIP_ZUIHO_AES.v is the topmost module of the design to be implemented on SASEBO.
- The topmost module contains instantiations of system files and RTL file for AES core to be synthesized.
- AES_Composite_enc.v is the RTL file pertaining to the AES core.
- CHIP_ZUIHO_AES.bit is the bitstream generated.
